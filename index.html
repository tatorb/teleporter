📝 Guión

Pegá acá el JSON de tu guión y tocá Cargar guión. Se guarda solo en tu navegador. Pasale la plantilla a Claude para que adapte cualquier guión a este formato.

Espacio — Play / Pausa
↑ / ↓ — Velocidad
+ / − — Tamaño texto
← / → — Saltar bloque
R — Reiniciar
B — Fondo negro/blanco
M — Espejo horizontal
L — Línea de lectura
F — Pantalla completa
G — Panel de guión
Esc — Salir / cerrar
Home — Ir al inicio

Durante la reproducción la barra superior se oculta sola para que la cámara solo capture el texto. Movés el mouse o tocás la pantalla para que vuelva.
